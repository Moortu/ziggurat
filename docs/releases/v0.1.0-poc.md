First public build of Ziggurat: Zig scripts for Godot 4.7. This is a
**proof of concept**. It works end to end on Linux; Windows and macOS are
early. The project will probably not be developed further, so do not build
anything important on it; forks are welcome.

## What works

- Zig scripts as real Godot scripts: attach them to nodes, edit fields in
  the Inspector (with ranges, flags and other hints), call their methods and
  connect to their signals from GDScript.
- Building in the editor: on save, on Play, or with Project > Tools > Build
  Zig Scripts. The Zig panel shows every error with its file and line.
- Hot reload: saving a script swaps the new code into the running game and
  the editor, and the instances keep their field values.
- Zig 0.17.0 download from the editor, checked with minisign.
- Export of games with Zig scripts for Linux x86_64, Windows x86_64 and
  macOS (universal, experimental).

## Platform status

- **Linux x86_64:** tested (editor and exported games).
- **Windows x86_64:** tested under Wine only. Building Zig scripts in a
  Windows editor is untested, because the Windows Zig compiler does not run
  under Wine.
- **macOS 11.0+ (arm64 and x86_64):** built and checked on Linux only;
  nothing has run on a Mac yet.

## Install

Unpack `ziggurat-0.1.0.zip` into your Godot 4.7 project folder, then
follow the steps in the
[README](https://github.com/Moortu/ziggurat#install). The add-on's own
guide is `addons/ziggurat/README.md` inside the zip.

## Known limits

- Godot 4.7 only (`compatibility_minimum` and `compatibility_maximum` are
  4.7). Zig 0.17.0 only.
- The zip holds every platform (about 60 MiB, about 630 MiB unpacked,
  mostly the four SDK copies).
- A Zig script cannot inherit from another Zig script yet.
- On macOS, a user `export fn` in a script fails the macOS export.
- The libraries are not code-signed (the macOS arm64 code has an ad-hoc
  signature only).

The package is reproducible: building this tag with `zig build package`
gives the same bytes as the SHA-256 below.
